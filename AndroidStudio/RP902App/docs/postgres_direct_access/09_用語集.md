# 09 用語集

| 用語 | 意味 |
| --- | --- |
| PostgreSQL direct access | Android アプリが PostgreSQL の View / Function を直接利用する構成 |
| View | Android や XCgate に公開する読み取り用境界 |
| Function | Android から呼ぶ取得・登録用境界 |
| Constraint | PostgreSQL 側で整合性を守る制約 |
| Work context | 作業対象を特定する情報 |
| Rule bundle | 端末内判定に必要な帳票ルールのまとまり |
| Equipment snapshot | 端末内判定に必要な設備マスタの snapshot |
| Local judgement | Android 端末内で行う判定 |
| Read result registration bundle | PostgreSQL function へ渡す登録単位 |
| Pending write | 登録失敗後に後で再実行するための保留 |
| Final result view | XCgate が参照する最終結果 View |
| Audit | いつ、どの端末が、どの session を登録したかを追跡する記録 |
