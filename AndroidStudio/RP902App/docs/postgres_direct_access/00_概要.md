# 00 概要

このフォルダは、Android アプリから PostgreSQL を直接利用するための引き継ぎ資料です。

## 現行方針

- 専用中間アプリケーションは置かない。
- Android アプリが PostgreSQL の View / Function を利用する。
- Android アプリが作業対象、帳票ルール、設備マスタを取得する。
- Android アプリが端末内判定を行う。
- Android アプリが読取結果を PostgreSQL function 経由で登録する。
- XCgate は PostgreSQL の final result view を参照する。
