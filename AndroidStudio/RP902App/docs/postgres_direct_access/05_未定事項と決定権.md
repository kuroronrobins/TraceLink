# 05 未定事項と決定権

| 項目 | 決めること | 推奨決定者 |
| --- | --- | --- |
| work context key | 帳票、作業、端末をどう特定するか | 業務設計 / DB 設計 |
| rule version | Android がどの rule version で判定したかをどう残すか | 業務設計 / DB 設計 |
| equipment snapshot | 読取時点の設備マスタ version をどう残すか | DB 設計 |
| registration idempotency | 同じ session の二重登録をどう扱うか | DB 設計 / Android |
| pending write retention | 端末内保留を何日残すか | 運用設計 |
| XCgate final view | XCgate が必要とする列と粒度 | XCgate / 業務設計 |

## 決定前にやらないこと

- Android に table 名を直書きする。
- Function の入力 JSON 形式をコードへ固定する。
- 端末内判定結果の enum を業務合意なしに確定する。
