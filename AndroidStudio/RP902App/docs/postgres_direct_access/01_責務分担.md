# 01 責務分担

| 要素 | 担当すること | 担当しないこと |
| --- | --- | --- |
| Android アプリ | RP902 接続、RFID 読取、作業対象確定、rule/master 取得、端末内判定、読取結果登録、pending write 管理 | PostgreSQL table 構造の直接露出、XCgate 帳票保存 |
| PostgreSQL | Android 用 View / Function、帳票ルール、設備マスタ、読取結果、制約、監査情報、final result view | Android UI、RP902 SDK 呼び出し、端末内 session state |
| XCgate | final result view の参照、帳票上の結果表示 | RFID 読取、端末内判定、読取結果登録 |

## Android 内の責務

| 責務 | 予定クラス |
| --- | --- |
| 作業対象取得 | `WorkContextRepository` |
| 帳票ルール取得 | `RuleRepository` |
| 設備マスタ取得 | `EquipmentMasterRepository` |
| session 内重複除去 | `InventorySession` |
| 端末内判定 | `ReadJudgementService` |
| 結果登録 | `ReadResultRepository` |
| 登録失敗保留 | `PendingWriteQueue` |
