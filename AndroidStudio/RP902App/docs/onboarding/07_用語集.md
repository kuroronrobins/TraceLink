# 07 用語集

この資料は、コードやログに出てくる用語を初学者向けに説明します。

| 用語 | 説明 |
| --- | --- |
| RFID | 電波を使ってタグの情報を読む仕組みです。バーコードのように直接見えなくても読める場合があります。 |
| UHF | RFID の周波数帯の一種です。このアプリでは RP902 の UHF 読取を扱います。 |
| RP902 | Unitech の RFID reader 機器です。Android 端末とは Bluetooth で接続する想定です。 |
| EPC | RFID タグに入っている識別子です。このアプリではタグを区別する主な値です。 |
| Inventory | RFID タグを探して読み続ける処理です。Start で開始し、Stop で止めます。 |
| Session | ひとまとまりの読取作業です。同じセッション内では同一 EPC を重複表示しません。 |
| callback | 外部処理が終わったときやイベントが来たときに、SDK からアプリへ呼び返される通知です。タグ読取も callback で届きます。 |
| Flow | Kotlin coroutine のデータの流れです。状態やタグ読取イベントを非同期に流します。 |
| StateFlow | 現在値を持つ Flow です。画面は StateFlow を監視して表示を更新します。 |
| SharedFlow | イベントを流す Flow です。tag read や gateway diagnostic に使っています。 |
| ViewModel | 画面に必要な状態を作り、画面操作を repository へ渡す係です。 |
| Repository | アプリの処理をまとめる係です。reader、重複除去、upload、ログなどを組み合わせます。 |
| Gateway | 外部機器や外部 SDK とつながる窓口です。このアプリでは `ReaderGateway` が reader の窓口です。 |
| Adapter boundary | 外部 SDK の影響をアプリ全体へ広げないための境界です。`RealRp902Gateway` が該当します。 |
| vendor SDK | Unitech が提供するライブラリです。RP902 へ接続し、inventory を実行するために使います。 |
| fake reader | 実機なしで動作確認するための reader 実装です。既定ではこれを使います。 |
| real reader | 本物の RP902 を使う reader 実装です。Settings で明示的に選びます。 |
| preflight | 実機接続前の事前確認です。MAC、権限、Bluetooth 状態などを見ます。 |
| runtime permission | Android 実行中にユーザーへ許可を求める権限です。Bluetooth 権限などがあります。 |
| MAC address | Bluetooth 機器を識別するアドレスです。今回運用の RP902 既定値は `DC:0D:30:DA:0F:3C` で、必要なら Settings 画面で別 MAC に編集できます。 |
| retry queue | upload に失敗した payload をあとで再送できるように残す場所です。 |
| upload repository | backend 送信を担当する契約です。現在は fake 実装です。 |
| structured log | level、category、message などに分かれたログです。文字列だけのログより後で追いやすくなります。 |
| UDF | Unidirectional Data Flow の略です。データが一方向に流れる設計で、画面が内部状態を直接書き換えないようにします。 |
| Compose | Android の画面を Kotlin で書く仕組みです。このアプリの UI は Jetpack Compose で作ります。 |
| Composable | Compose の画面部品です。`@Composable` が付いた関数です。 |
| DI | Dependency Injection の略です。必要な部品を外から渡す設計です。このアプリでは `AppContainer` が手動で組み立てています。 |
| in-memory | メモリ上だけに保存することです。アプリを終了すると消えます。 |
| durable storage | アプリを終了しても残る保存先です。DataStore や Room などが候補です。 |
| DMService | vendor SDK 周辺で出てくる Unitech 側サービス候補です。現時点では RP902 inventory path に必須とは断定していません。 |
| key mapping | RP902 の物理トリガーなどを Android 側入力に割り当てる仕組みです。画面の Start ボタン動作とは別に確認が必要です。 |
| DisplayOutput | RP902 の画面表示出力に関係する vendor SDK 型です。実機で JNI crash が出たため、現在は real adapter 内で抑止しています。 |
| JNI | Java/Kotlin と native library をつなぐ仕組みです。vendor SDK の内部で使われます。 |
