# 07 用語集

| 用語 | 説明 |
| --- | --- |
| RFID | 電波を使ってタグの情報を読む仕組みです。 |
| UHF | RFID の周波数帯の一種です。このアプリでは RP902 の UHF 読取を扱います。 |
| RP902 | Unitech の RFID reader 機器です。Android 端末とは Bluetooth で接続する想定です。 |
| EPC | RFID タグに入っている識別子です。このアプリではタグを区別する主な値です。 |
| Inventory | RFID タグを探して読み続ける処理です。Start で開始し、Stop で止めます。 |
| Session | ひとまとまりの読取作業です。同じ session 内では同一 EPC を重複表示しません。 |
| Work context | 作業対象を表す情報です。帳票や作業者、対象範囲を特定します。 |
| Rule bundle | 端末内判定で使う帳票ルールのまとまりです。 |
| Equipment snapshot | 端末内判定で使う設備マスタの snapshot です。 |
| Local judgement | Android 端末内で rule/master と読取結果を照合して判定する処理です。 |
| Read result registration bundle | PostgreSQL function へ渡す読取結果登録単位です。 |
| Pending write | PostgreSQL 登録に失敗した bundle を後で再実行するための保留です。 |
| View / Function | Android が PostgreSQL を安全に使うための公開境界です。table 直叩きの代わりに使います。 |
| XCgate | PostgreSQL の final result view を参照し、帳票上で結果を見る役割です。 |
| Flow | Kotlin coroutine のデータの流れです。 |
| StateFlow | 現在値を持つ Flow です。画面は StateFlow を監視して表示を更新します。 |
| ViewModel | 画面に必要な状態を作り、画面操作を repository へ渡す係です。 |
| Repository | アプリの処理をまとめる係です。reader、重複除去、結果登録、ログなどを組み合わせます。 |
| Gateway | 外部機器や外部サービスとつながる窓口です。 |
| Adapter boundary | 外部 SDK の影響をアプリ全体へ広げないための境界です。 |
| vendor SDK | Unitech が提供するライブラリです。RP902 へ接続し、inventory を実行するために使います。 |
| fake reader | 実機なしで動作確認するための reader 実装です。 |
| real reader | 本物の RP902 を使う reader 実装です。Settings で明示的に選びます。 |
| preflight | 実機接続前の事前確認です。MAC、権限、Bluetooth 状態などを見ます。 |
| structured log | level、category、message などに分かれたログです。 |
| UDF | Unidirectional Data Flow の略です。データが一方向に流れる設計です。 |
| Compose | Android の画面を Kotlin で書く仕組みです。 |
| DI | Dependency Injection の略です。このアプリでは `AppContainer` が手動で組み立てています。 |
| in-memory | メモリ上だけに保存することです。アプリを終了すると消えます。 |
| durable storage | アプリを終了しても残る保存先です。Room などが候補です。 |
