# 04 クラス責務一覧

主要クラスごとに「何を担当するか」「何を担当しないか」をまとめます。

## 入口と UI

| クラス | 担当すること | 担当しないこと |
| --- | --- | --- |
| `MainActivity` | Android 起動点、`AppContainer` と ViewModel 作成 | 業務ロジック、reader 操作、結果登録 |
| `AppContainer` | アプリ内依存を手動で組み立てる | 画面表示、実処理の詳細 |
| `Rp902App` | 画面切替、権限 launcher、Bluetooth settings 起動 | reader / 結果登録の実処理 |
| `InventoryScreen` | 状態表示、ボタン callback 通知 | 重複除去、結果登録判断、reader SDK 呼び出し |
| `InventoryViewModel` | repository state を UI state に変換 | vendor SDK、SQL、重複除去 |
| `LogsScreen` | 構造化ログ一覧の表示 | ログ生成、ログ保存 |

## Inventory workflow

| クラス | 担当すること | 担当しないこと |
| --- | --- | --- |
| `InventoryRepository` | Inventory 機能の app-owned 契約 | 実装詳細 |
| `DefaultInventoryRepository` | UI 操作に対応する処理順序、repository state 更新、log 集約、retry orchestration | vendor SDK 詳細、SQL、判定ルール本体、登録 bundle 構造の決定 |
| `InventorySession` | 同一 session 内 EPC の正規化と重複除去 | reader 接続、PostgreSQL 登録、rule/master 取得、判定、bundle 生成 |
| `InventoryTag` | 重複除去後のタグ集約モデル | callback raw data の解釈 |

## 新方針の差し替え点

| クラス | 担当すること | 担当しないこと |
| --- | --- | --- |
| `WorkContextRepository` | 作業対象 context の取得 | UI 表示 |
| `RuleRepository` | 帳票ルール bundle の取得 | 判定実行 |
| `EquipmentMasterRepository` | 設備マスタ snapshot の取得 | 判定実行 |
| `ReadJudgementService` | 端末内判定 | DB 接続、UI 表示 |
| `ReadResultBundleFactory` | session snapshot と判定結果から登録 bundle を作る | session 内重複除去、DB 登録 |
| `ReadResultRepository` | 判定済み読取結果の登録 | pending write 管理 |
| `PendingWriteQueue` | 登録失敗 bundle の保留 | 登録実行 |
| `PostgresGateway` | PostgreSQL View / Function 呼び出し境界 | UI/ViewModel からの直接利用 |
| `PostgresWorkContextRepository` / `PostgresRuleRepository` / `PostgresEquipmentMasterRepository` / `PostgresReadResultRepository` | repository 契約を `PostgresGateway` へ接続する adapter | SQL 文字列、View / Function 名の決定 |
| `JdbcPostgresGateway` | pgJDBC で View / Function を呼ぶ実 gateway | repository 責務、判定、UI state |
| `PostgresConnectionSettings` | PostgreSQL 接続設定 | 認証情報の保管元 |
| `PostgresSchema` / `PostgresSqlStatements` | schema / View / Function 名と SQL の集約 | data.postgres 外への SQL 公開 |
| `PostgresRowMappers` / `ReadResultBundleJsonEncoder` | DB row と JSONB 引数の変換 | domain model の業務判断 |

## 現在の fake / placeholder 実装

| クラス | 担当すること | 担当しないこと |
| --- | --- | --- |
| `FakeWorkContextRepository` | 固定 work context を返す | XCgate 帳票連携 |
| `FakeRuleRepository` | 固定 rule bundle を返す | 本番ルール評価 |
| `FakeEquipmentMasterRepository` | fake reader の EPC に対応する設備 snapshot を返す | 本番設備マスタ同期 |
| `SimpleReadJudgementService` | master 存在確認と設備種別許可の最小判定 | 帳票別の詳細ルール |
| `DefaultReadResultBundleFactory` | context/rule/equipment/judgement を登録 bundle に集約する | DB 接続、retry 判断 |

## Reader 周辺

| クラス | 担当すること | 担当しないこと |
| --- | --- | --- |
| `ReaderGateway` | reader 操作の共通契約 | fake/real の実装詳細 |
| `ConfigurableReaderGateway` | `ReaderSettings` に応じて fake/real を切り替える | vendor API 直接操作の詳細 |
| `FakeReaderGateway` | 実機なしで接続と tag read を模擬する | vendor SDK 呼び出し |
| `RealRp902Gateway` | Unitech SDK を `ReaderGateway` に変換する adapter | UI 表示、結果登録 |
| `Rp902TagEventMapper` | vendor tag callback の raw 値を app の `ReaderTagRead` へ安全変換 | repository 更新 |

## Log

| クラス | 担当すること | 担当しないこと |
| --- | --- | --- |
| `EventLogStore` | 構造化ログ保存契約 | ログ文言生成 |
| `InMemoryEventLogStore` | in-memory log 保存 | ファイル出力 |
| `AppLogEntry` | ログ 1 件の構造 | 表示レイアウト |
