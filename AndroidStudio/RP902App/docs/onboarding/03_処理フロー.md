# 03 処理フロー

この資料では、ユーザー操作ごとに内部処理がどう進むかを説明します。

## 全体フローチャート

```mermaid
flowchart TD
    Launch["アプリ起動"] --> Container["AppContainer が依存を作る"]
    Container --> VM["ViewModel を作る"]
    VM --> UI["Compose 画面を表示"]
    UI --> Settings{"Settings で real reader を選ぶ？"}
    Settings -- "いいえ" --> Fake["fake reader のまま"]
    Settings -- "はい" --> Preflight["MAC/権限/Bluetooth preflight"]
    Fake --> Work["作業対象確定"]
    Preflight --> Work
    Work --> Rule["rule bundle 取得"]
    Rule --> Equipment["equipment snapshot 取得"]
    Equipment --> Connect["Connect"]
    Connect --> Start["Start inventory"]
    Start --> Read["RFID read"]
    Read --> Dedupe["session 内重複除去"]
    Dedupe --> Judge["local judgement"]
    Judge --> Register["PostgreSQL function で結果登録"]
    Register --> Done["結果参照"]
```

## Tag 読取の詳細フロー

```mermaid
sequenceDiagram
    participant RP902 as RP902 / vendor SDK
    participant Real as RealRp902Gateway
    participant Repo as DefaultInventoryRepository
    participant Session as InventorySession
    participant VM as InventoryViewModel
    participant UI as InventoryScreen

    RP902->>Real: onRfidUhfReadTag(rawTag, params)
    Real->>Real: raw data を安全に検査
    Real->>Real: ReaderTagRead へ変換
    Real-->>Repo: tagReads Flow
    Repo->>Session: record(read)
    Session-->>Repo: 重複除去後 tags
    Repo-->>VM: InventoryRepositoryState 更新
    VM-->>UI: InventoryUiState 更新
```

## 結果登録の詳細フロー

```mermaid
flowchart TD
    A["Register 押下"] --> B["InventorySession.toRegistrationBundle"]
    B --> C{"tags は空？"}
    C -- "はい" --> D["RegistrationState.Failed と警告ログ"]
    C -- "いいえ" --> E["RegistrationState.Registering"]
    E --> F["ReadResultRepository.register"]
    F --> G{"成功？"}
    G -- "はい" --> H["RegistrationState.Completed"]
    G -- "いいえ" --> I["PendingWriteQueue.enqueueFailure"]
    I --> J["RegistrationState.Failed"]
```

現在の `FakeReadResultRepository` は fake 実装です。PostgreSQL 実接続時は `ReadResultRepository` の別実装を追加します。

## 異常時のフロー

| 異常 | 主な検出場所 | どう扱うか |
| --- | --- | --- |
| MAC 未設定 | `ReaderConnectionPreflight` | 接続前に止め、Settings/Logs に理由を出す |
| 権限不足 | `ReaderConnectionPreflight` | vendor SDK 呼び出し前に止める |
| Bluetooth 無効 | `ReaderConnectionPreflight` | Bluetooth settings へ誘導 |
| vendor connect 失敗 | `RealRp902Gateway.connect` | `ReaderConnectionState.Error` とログ |
| tag callback の raw EPC が空 | `Rp902TagEventMapper` | Warning log を出して無視 |
| 結果登録失敗 | `DefaultInventoryRepository` | pending write に保存 |
| repository command 例外 | `runReaderCommand` | Error log に残す |
