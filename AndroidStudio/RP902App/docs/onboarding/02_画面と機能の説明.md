# 02 画面と機能の説明

この資料では、画面で押すボタンが内部のどのコードにつながるかを説明します。

## 画面構成

| 画面 | ファイル | 目的 |
| --- | --- | --- |
| Inventory | `ui/inventory/InventoryScreen.kt` | reader 接続、inventory 開始/停止、タグ一覧、結果登録 |
| Logs | `ui/logs/LogsScreen.kt` | app 内で発生した構造化ログを見る |
| Settings | `ui/settings/SettingsScreen.kt` | fake/real 切替、RP902 MAC、Bluetooth 権限と preflight 確認 |

## Inventory 画面

| 表示 | 意味 | 主な元データ |
| --- | --- | --- |
| Reader | reader の接続状態 | `ReaderConnectionState` |
| Inventory | 読取中かどうか | `InventoryRepositoryState.isInventoryRunning` |
| Unique tags | session 内の重複除去後 EPC 件数 | `InventorySession.snapshot()` |
| Registration | 結果登録の状態 | `RegistrationState` |
| Pending writes | 登録失敗後の保留件数 | `PendingWriteQueue.pendingWrites` |
| Tags | 読み取った EPC 一覧 | `InventoryTag` |
| Recent log | 直近ログ | `AppLogEntry` |

## ボタンと内部処理

| ボタン | 画面 callback | ViewModel | Repository | その先 |
| --- | --- | --- | --- | --- |
| Connect | `onConnect` | `connect()` | `connect()` | `ConfigurableReaderGateway.connect()` |
| Disconnect | `onDisconnect` | `disconnect()` | `disconnect()` | active gateway の disconnect |
| Start | `onStartInventory` | `startInventory()` | `startInventory()` | active gateway の `startInventory()` |
| Stop | `onStopInventory` | `stopInventory()` | `stopInventory()` | active gateway の `stopInventory()` |
| Register | `onRegister` | `registerCurrentSessionResults()` | `registerCurrentSessionResults()` | `ReadResultRepository.register()` |
| Retry writes | `onRetryPendingWrites` | `retryPendingWrites()` | `retryPendingWrites()` | `PendingWriteQueue` の bundle を再実行 |
| Clear | `onClearSession` | `clearSession()` | `clearSession()` | `InventorySession.clear()` |

重要な点:

- Composable はボタンが押されたことを伝えるだけです。
- 結果登録や reader 操作の判断は ViewModel / Repository が担当します。
- UI state は domain/data state の投影です。

## Logs 画面

Logs 画面は `ui/logs/LogsScreen.kt` です。ここに出るログは、repository や gateway が `EventLogStore` に保存した `AppLogEntry` です。

## Settings 画面

Settings 画面は reader の接続前準備を行います。fake / real の切替、MAC 入力、権限状態、Bluetooth 状態を扱います。PostgreSQL 接続情報はこの画面へ直接混ぜず、後続で専用設定境界を設けます。
